# EQ-5D-5L — plain-language guide

**What it measures:** Health-related quality of life (Quality of Life)

**Who it's for:** Adults · **How it's given:** Self-report

**Length:** 5 items · **Scores from -0.594 to 1

## What this test is

EQ-5D-5L (EQ-5D-5L) is a self-report questionnaire that measures **health-related quality of life**. This instrument is well validated in the research literature.

## How it's scored

**Method:** algorithm. EQ-5D-5L produces (1) a health-state profile (5-digit code like 12321 — one digit per dimension) and (2) an INDEX score derived by country-specific value sets (utility weights from general-population preferences; UK EQ-5D-5L value set: Devlin, Shah & van Hout 2017 — range -0.594 to 1.0, where 1 = full health, 0 = death-equivalent). (3) EQ-VAS = self-rated health 0-100. Validation (Herdman et al. 2011 for 5L): psychometrics support 5-level granularity. Value sets are country-specific — no universal cutoffs.

## What the scores mean

| Score range | Band | What it means |
|---|---|---|
| -0.594–1 | **Index score (country-specific value set)** | EQ-5D-5L index from country value set: 1 = full health, 0 = death-equivalent utility, negative = worse than death. Compare to normative values per country. Use official EuroQol value set for the relevant country/region. |
