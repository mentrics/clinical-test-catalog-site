DOCS — plain-language guide

What it measures: OCD dimensions (OCD)

Who it's for: Adults · How it's given: Self-report

Length: 20 items · **Scores from 0 to 100

What this test is

DOCS (Dimensional Obsessive-Compulsive Scale) is a self-report questionnaire that measures ocd dimensions. This instrument is well validated in the research literature.

Item text

The exact question wording is not reproduced here (licensing/copyright). The scoring logic below is still fully documented.

How it's scored

Method: sum. 4 subscales of 10 items each (Contamination, Responsibility for harm, Unacceptable thoughts, Symmetry/Completeness) + total. Each subscale scored 0-40; total 0-160. Catalog lists DOCS total as 0-100 but the 4x10-item structure gives 0-160 — catalog row item count and range need verification. Validation (Abramowitz et al. 2010): alphas .80-.88 across subscales.

Subscales

  • Contamination — sum
  • Responsibility for harm — sum
  • Unacceptable thoughts — sum
  • Symmetry/Completeness — sum
