RBANS — plain-language guide

What it measures: Memory (Cognition)

Who it's for: Adults/older adults · How it's given: Performance

Length: Variable items · **Scores from 40 to 160

What this test is

RBANS (Repeatable Battery for the Assessment of Neuropsychological Status) is a performance questionnaire that measures memory. This instrument is well validated in the research literature.

How it's scored

Method: algorithm. RBANS: 5 index scores — Immediate Memory, Visuospatial/Constructional, Language, Attention, Delayed Memory + Total Scale Index. Subtest raw scores → scaled scores → index T-scores via age-stratified normative tables. Validation (Randolph 1998; Duff et al. 2006 psychometric update): reliability .88-.95 for indices. Higher = better cognitive function; interpretation requires qualified-clinician administration.

What the scores mean

Score range Band What it means
40–160 Norm-referenced index T-scores Indices + Total Scale interpreted on the T-metric (M = 100, SD = 15): <70 = extremely low, 70-79 borderline, 80-89 low average, 90-109 average, 110-119 high average, 120+ superior. Official RBANS norm tables (Randolph 1998) required.
