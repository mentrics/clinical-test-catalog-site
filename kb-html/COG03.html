WAIS-IV — plain-language guide

What it measures: Adult intelligence (Cognition)

Who it's for: Adults · How it's given: Performance

Length: Variable items · **Scores from 40 to 160

What this test is

WAIS-IV (Wechsler Adult Intelligence Scale-Fourth Edition) is a performance questionnaire that measures adult intelligence. This instrument is well validated in the research literature.

The exact question wording is not reproduced here (licensing/copyright). The scoring logic below is still fully documented.

How it's scored

Method: algorithm. WAIS-IV (10 core subtests): 4 index scores — Verbal Comprehension (VCI), Perceptual Reasoning (PRI), Working Memory (WMI), Processing Speed (PSI) + Full-Scale IQ (FSIQ). Subtest scaled scores (M=10, SD=3) → index scores via age-stratified normative conversion tables (M=100, SD=15). Validation (Wechsler 2008): reliability .92-.96 for indices. Interpretation requires qualified-clinician administration (individually administered, standardized materials).

What the scores mean

Score range Band What it means
40–160 Norm-referenced IQ scale FSIQ and index scores interpreted on the IQ metric (M = 100, SD = 15): 130+ very superior, 120-129 superior, 110-119 high average, 90-109 average, 80-89 low average, 70-79 borderline, <70 extremely low. Official WAIS-IV norm tables (Wechsler 2008) required — never hand-compute.
